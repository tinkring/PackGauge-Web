A few things worth knowing

Useful data.
Clear boundaries.

Built for a closer look, not a blanket verdict.

Does it tell me whether a battery is safe?

No. PackGauge displays available pack-reported data. A scan does not establish safety, authenticity, capacity, or health. Balanced readings and an absent fault record are not an approval to keep using a suspect pack. Read the full limitations.

Will every M18 pack show the same data?

No. Hardware and firmware vary, including within a nominal family. Some tested Forge firmware exposes core readings and totals but not many detailed history blocks. Unavailable data stays unavailable. Check the compatibility scope.

Do I need Wi-Fi or a computer to scan?

The standalone reader does not require a computer for scanning. Wi-Fi is used for configured network features such as emailing reports. Saved-scan storage requires a micro-SD card.

Can PackGauge charge or repair a pack?

No. It is a diagnostic reader, not a charger or repair tool. The current user workflow does not offer battery reset, balancing, unlocking, or reprogramming controls.
